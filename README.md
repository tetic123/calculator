## 3. Калькулятор

# Калькулятор

Калькулятор на JS с поддержкой цепочки операций, 
истории вычислений и обработкой ошибок.

## Стек

- HTML
- CSS
- JS

## Возможности

- Базовые операции: сложение, вычитание, умножение, деление
- Цепочка операций
- Десятичные числа
- Смена знака, проценты
- Очистка и удаление последнего символа
- Обработка ошибок: деление на ноль, некорректный ввод

## Что реализовано

- Логика вычислений с учётом приоритета операций
- Компонентная структура: дисплей, клавиатура
- Защита от некорректного ввода
